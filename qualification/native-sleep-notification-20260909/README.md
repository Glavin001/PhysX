# Remove nonphysical pre-upload GPU sleep notifications

ScScene now queues GPU sleep finalization only for an in-scene, already-uploaded dynamic body. Creation calls deactivate before GPU registration, so checking FIRST_BODY_COPY_GPU alone is insufficient: the creation-time notInScene guard is necessary. Explicit pre-upload sleep is represented by CPU initial state; no resident motion exists to reset. CPU event callbacks remain unchanged. The fragment allocator no longer immediately drains one bogus sleep notification per new body. Actual uploaded-body sleep/rollback is unchanged.

At diagnostic first-fracture tick 48, accepted sleepCommit calls fall **6,345 → 1**, with union 4.929 → 0.247 ms. The remaining call finalizes real sleep. These are instrumented intervals, not untraced speedup estimates. The [generated phase report](profile-counts/report.md) now includes call counts and longest call to avoid mistaking thousands of calls for one expensive GPU transaction.

[Initial untraced destruction screen](shots/report.md) and [fresh intact idle](idle/report.md): 256 buildings, 113,664 chunks, 229,376 bonds; 768 physical shots versus zero shots, 600 steps / 10 simulated seconds per run. Complete destruction peak 137.367 → 134.462 ms; complete mean 45.656 → 44.701 ms. All-step peak 161.286 → 159.793 ms includes first step. Idle remains intact. This single pair is not a guaranteed saving, endurance, 60 Hz or historical user-land parity. [Three runs per arm](repeated-shots/report.md) and [three intact-idle runs per arm](repeated-idle/report.md) are complete. Loaded peaks overlap: baseline 134.416–141.050 ms, candidate 131.285–138.123 ms. Means also overlap and startup has no robust improvement. Accepted as proven redundant lifecycle work deletion, not a proved full-run speedup.

Passed: nine ordinary native lifecycle tests (including correction boundary, wake, late impact and post-correction fracture), new 513-collider compound sleep/rollback plus three ordinary pre-upload sleep/wake controls (quiet native asset 2 chunks/1 bond), CUDA memcheck, exact 444-chunk/896-bond one-projectile wall (398 retained/46 detached/199 broken), and heavy every-tick full GPU/CPU mapping audit on the 256-building/768-shot/600-step scene. Heavy audits are excluded from performance timing. Direct GPU API remains off, sleeping on, timestep 1/60, correction limit one. No physical limits or tolerances changed.
