# Precision experiment preparation

Primary reference: [Bake, Carson and Ma, Forward and backward error bounds for a mixed precision preconditioned conjugate gradient algorithm (2025)](https://arxiv.org/html/2510.11379v1). Their analysis permits lower-precision preconditioner application under conditioning and rounding-error assumptions; it does not guarantee arbitrary low-precision PCG or fast convergence. It also distinguishes recursive residuals from the true original-equation residual.

Repository implications (our inference, not a theorem established for this engine): retain the authoritative original-equation residual, projection and final physical gates. An approximate preconditioner needs its own explicit error/positivity assessment and scaling against overflow/underflow. Preserve existing exact block-inverse oracles; do not quietly relax their tolerances. The engine works on a quotient with null motions, so SPD results cannot simply be applied to the unprojected singular operator. Setup, extra normalization and any increased iteration count must enter full-step timing.

N01 already demonstrates that an apparently cheap convergence-check change can break early exact convergence. N02 demonstrates that removing intermediate projection can stall scaled loads. Those failures make a naive cast or skipped true-residual check unjustified. N08 first removes repeated reciprocal computation without changing precision. If low precision is pursued next, qualify the new approximate preconditioner independently and use existing end-to-end convergence/material checks; judge time to the required quality.
